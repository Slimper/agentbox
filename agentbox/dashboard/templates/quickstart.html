{{ m.icon('inbox', 16) }} Simulate an inbound reply locally
Any SMTP client can deliver to the edge on port {{ smtp_port }}. The message lands in the inbox thread and fires message.received.
python - <<'PY'
import smtplib
from email.message import EmailMessage
m = EmailMessage(); m["From"] = "Vendor <vendor@example.com>"; m["To"] = "your-agent@{{ managed_domain }}"
m["Subject"] = "Re: hello"; m.set_content("Reply from the outside world")
with smtplib.SMTP("localhost", {{ smtp_port }}) as s: s.send_message(m)
